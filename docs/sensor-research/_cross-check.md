# Cross-check of the fourteen topic files: MODIS and VIIRS active-fire reference

Cross-checked 2026-11-13. All fourteen topic files in this folder were read in full. Where two files gave different values for the same thing, the cross-checker opened the primary source again on 2026-11-13. Each resolution below gives the value to use, the source, and the reason.

How to read the tags:
- **[resolved]**: the cross-checker opened the source on 2026-11-13 and it settles the question.
- **[resolved by reasoning]**: both values are on primary pages and they describe different things. The note explains the difference.
- **[unresolved]**: the conflict could not be settled from open pages.
- **[computed]**: the cross-checker's own arithmetic. These values are not printed by any source.

File short names used below: terra-aqua, modis-instr, jpss, viirs-instr, modis-alg, viirs-alg, csv-schema, streams, conf-type, outages, coverage, pixel, upstream, calib.
